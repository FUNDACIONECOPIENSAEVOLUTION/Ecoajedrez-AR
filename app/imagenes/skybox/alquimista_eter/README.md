# Alquimista / Éter · SKYBOX ECOAJEDREZ

Tablero del juego asociado (más adelante): `alquimia`. **Fase actual: subir y probar 6 caras, sin integrar batallas finales.**

Sube aquí seis archivos WebP con nombres exactos:

1. `px.webp` — derecha (+X)
2. `nx.webp` — izquierda (−X)
3. `py.webp` — cielo (+Y)
4. `ny.webp` — suelo (−Y)
5. `pz.webp` — frente (+Z)
6. `nz.webp` — atrás (−Z)

Todos cuadrados, **resolución idéntica** (1024×1024 móvil o 2048×2048 para más definición), hasta 3 MB cada uno. Seis proyecciones de cámara cúbica desde **un solo punto**, FOV 90° con bordes continuos. No convertir seis escenas distintas en seis caras ni estirar imágenes panorámicas.

[Instrucciones generales](../README.md). Subir usando Add file → Upload files → Commit changes en main.
