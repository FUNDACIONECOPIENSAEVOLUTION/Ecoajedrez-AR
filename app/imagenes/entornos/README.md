# Fondos WebP de reinos de ECOAJEDREZ — modo 3D

Sube **un fondo por cada tablero** en esta carpeta. Son paisajes que se mostrarán detrás del tablero al jugar en 3D. Los diseños y las 64 casillas del tablero NO se reemplazan.

## Nombres exactos de los trece fondos

- `entorno_alquimia.webp` → tablero alquimia
- `entorno_celta.webp` → tablero celta
- `entorno_cyber.webp` → tablero cyber
- `entorno_cosmos.webp` → tablero cosmos
- `entorno_amatista.webp` → tablero amatista
- `entorno_dorado.webp` → tablero dorado
- `entorno_atlantis.webp` → tablero atlantis
- `entorno_hielo.webp` → tablero hielo
- `entorno_lava.webp` → tablero lava
- `entorno_egipto.webp` → tablero egipto
- `entorno_gotico.webp` → tablero gotico
- `entorno_cristales.webp` → tablero cristales
- `entorno_steampunk.webp` → tablero steampunk

Recomendación: **WebP** (extensión `.webp`, no `.web`), panorámico 16:9, 1920×1080 o 2048×1152, 80–88 % de calidad, **menos de 3 MB por archivo**.

En GitHub elige **Add file → Upload files**, carga estas imágenes y guarda en `main` con **Commit changes**. En cada publicación, GitHub Actions valida los archivos, los copia a Pages y genera un manifiesto solo con los fondos realmente presentes. Así cada diseño encuentra su pareja sin seleccionar el escenario individualmente. Si falta alguna imagen, se usa temporalmente el fondo tradicional. El tablero clásico conserva la elección libre de escenarios. El modo AR conserva la imagen de la cámara, nunca el entorno ilustrado.
