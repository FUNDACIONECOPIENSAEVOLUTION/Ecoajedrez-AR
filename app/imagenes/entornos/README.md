## Solo faltan tres fondos exclusivos
Los tableros `alquimia`, `amatista` y `gotico` funcionan con las imágenes compartidas indicadas arriba. Para ponerles un reino único, sube cuando quieras alguno o todos estos tres archivos:
- `entorno_alquimia.webp` — laboratorio del alquimista, pociones, mercurio.
- `entorno_amatista.webp` — dimensión de cristal amatista y plata.
- `entorno_gotico.webp` — castillo gótico y necrópolis espectral.

**No es obligatorio subirlos:** cada pareja tablero-reino ya tendrá fondo jugable.

## Instrucciones
Carga los nuevos archivos en **esta misma carpeta** mediante Add file → Upload files → Commit changes en `main`. Usa WebP real, 16:9, aprox. 1920×1080, menos de 3 MB. Al terminar GitHub Pages, el manifiesto se regenera automáticamente y el juego prioriza los tres fondos exclusivos frente al fondo compartido sin cambios de código.

La selección del tablero activa su pareja en modo **3D**; en modo **AR** no se agrega ninguna imagen detrás de la cámara. Las imágenes `vista-` permanecen reservadas para galería y celebración; las `tablero_` siguen siendo texturas de casillas.
