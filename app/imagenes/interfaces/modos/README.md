# ECOAJEDREZ — Tarjetas visuales para elegir la modalidad

Esta es la carpeta oficial de las **tres imágenes del selector de experiencias**. No corresponde a los paisajes de los reinos ni a las seis caras del Skybox.

## Nombres exactos
| Archivo WebP | Modalidad | Descripción |
| --- | --- | --- |
| `01_3d_clasico.webp` | **3D CLÁSICO** | Tablero 3D jugable y paisaje panorámico del reino |
| `02_reino_360.webp` | **REINO 360°** | Tablero jugable dentro de un skybox cúbico |
| `03_ar_con_portal.webp` | **AR CON PORTAL** | Tablero en superficie real con portal decorativo |

**Carga directa:** https://github.com/FUNDACIONECOPIENSAEVOLUTION/Ecoajedrez-AR/upload/main/app/imagenes/interfaces/modos

Instrucciones:
1. Descargar y descomprimir el ZIP de las tres tarjetas.
2. Abrir el enlace de carga en GitHub, en la rama `main`.
3. Subir **los tres archivos .webp**, sin cambiar los nombres, mediante «Add file → Upload files» y «Commit changes».
4. No subir el ZIP cerrado; GitHub Pages necesita las tres imágenes separadas.

Las tarjetas están optimizadas a 1024 × 1024 píxeles. Son ilustraciones del menú; no modifican la jugabilidad, el tablero seleccionado, los Skyboxes ni la cámara AR.

El proceso de publicación de GitHub Pages ya está preparado para copiar cada imagen que exista con exactamente uno de estos nombres. Cuando se integren en el selector, se cargarán desde `./app/imagenes/interfaces/modos/`.
